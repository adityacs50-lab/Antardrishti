# prahari — 90-second demo script (speak this)

**One argument:** we detect **potential**, not consequence. Wi‑Fi off if possible.

## Before you start

```powershell
cd prahari
powershell -ExecutionPolicy Bypass -File .\scripts\demo_windows.ps1
```

Check: green **Air-gapped Engine · Online**; report count ~700; Engine Performance card shows a measurement date.
Before recording, confirm or override 3–5 reports so the live **HSE reviewer agreement** figure is not empty.

---

## 0:00–0:15 · Open — thesis + proof

Triage Queue opens on the thesis strip and the **Engine Performance** card.

> "Potential is not severity. Most systems rank injuries. We rank fatal energy with a missing barrier — and we measure it: **97.6% recall** on SIF precursors, 85.1% precision, 450 held-out reports, under 2 ms each. Those numbers are regenerated by a script, not typed in."

## 0:15–0:30 · Report A (the trap)

**Live Incident Sandbox** → click **Low severity** (or runbook `1 · Cut finger`).

> "Real injury. Everyone tracks this. **Low SIF potential** — the energy could never kill him."

## 0:30–0:55 · Report B (the thesis)

Click **Clear Potential SIF** — relief valve bypassed, flange blew out, nobody hurt.

> "Nothing happened. Anywhere else this is closed the same day. We call **Potential SIF**: pressure energy, barrier **bypassed**, Life-Saving Rule **Bypassing Safety Controls**."

Point at the **Hybrid engine signal**:

> "Hybrid, but not a black box: the NLP layer only extracts facts — here, 4 of 4 slots. Nine named rules decide. Same text, same verdict, every time."

Then click **Multi-rule · Hinglish**:

> "Field reports are code-mixed. Hot work, no permit, no gas test — three Life-Saving Rules from one Hinglish report."

Open the rule trace or a queue row's **Audit** drawer: highlighted spans + rule IDs.

## 0:55–1:15 · Patterns → action

Back on the Triage Queue, point at **Recommended Immediate Actions**.

> "One report is noise. The same barrier failing again at the same site is the pattern HSE must fund. Number one: install and enforce machine guarding at Moran — the same barrier failed six times." *(read the site and count off the card; they move with the data)*

Click it → the queue filters to Moran → **Export for HSE** → PDF summary.

> "And that goes to the HSE meeting as a PDF, straight from the queue."

## 1:15–1:30 · Close

Top bar → **Ontology**.

> "Everything the engine reasons with — Energy Wheel, barrier states, IOGP Life-Saving Rules — served from the engine itself. Every verdict is defendable to a regulator. Fully offline for OIL field conditions."

**If asked "is a model running?"** — the banner says Keyword fallback. Say so: the rules decide either way; the trained model would only improve fact extraction.

1. Triage: thesis strip + Engine Performance card

4. Sandbox: Multi-rule · Hinglish → secondary LSRs, highlighted spans
5. Triage: Recommended Actions → click → Export for HSE (PDF)
6. Ontology: Energy sources tab, search "harness"
