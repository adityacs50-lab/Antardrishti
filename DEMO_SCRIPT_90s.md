# prahari — 90-second demo script (speak this)

**One argument:** we detect **potential**, not consequence. Wi‑Fi off if possible.

## Before you start

```powershell
cd prahari
powershell -ExecutionPolicy Bypass -File .\scripts\demo_windows.ps1
```

Check: green **Engine online**; report count ~700; extractor badge (Keyword or ONNX).

---

## 0:00–0:10 · Open

Home opens straight on **Analyze**. Point at the thesis strip:

> "Potential is not severity. Most systems rank injuries. We rank fatal energy with a missing barrier."

## 0:10–0:30 · Report A (the trap)

Still at the top of Home, in Live Analysis → `1 · Cut finger in the workshop`

> "Real blood. First aid. Everyone tracks this. **Low SIF potential** — the energy could never kill him."

## 0:30–0:55 · Report B (the thesis)

Select the belt / pumping unit / missing guard / not isolated / **no injury** scenario.

> "Nothing happened. Closed the same day anywhere else. We call **Potential SIF** — mechanical energy past the threshold, direct control absent, Life-Saving Rule: **Energy Isolation**. Here is the rule trace."

Scroll down to the **Triage Queue** and click into a row with PSIF if needed → **Report Detail**: highlight spans + named rules.

## 0:55–1:15 · Patterns

Nav → **Patterns**. It leads with the accumulation alert, heatmap below.

> "One report is noise. The same barrier failing again at the same site is the precursor pattern HSE must fund."

## 1:15–1:30 · Close

Nav → **Rules**, then:

> "Neuro-symbolic: the model only extracts spans; the rule engine decides; every verdict is defendable to a regulator. Fully offline for OIL field conditions."
